# לשונית "נכסים" ב-Desk — קליטה מסורק הנדל"ן

הסורק רץ על מחשב חיצוני (אצל השמאי). בסוף כל סריקה הוא שולח את הנכסים לכתובת קליטה אחת, וה-Desk מציג אותם.

```
מחשב הסריקה ──POST + קוד סודי──▶ nadlanIngest (Cloud Function) ──▶ Firestore properties/{id}
                                                                  └▶ settings/nadlanScan
Desk (בעלים בלבד) ◀── קריאה + עדכון שדות מעקב בלבד ── Firestore
```

## חיפושים מנוהלים בדסק

החיפושים (עיר / מחיר / חדרים / סוג נכס) מוגדרים בלשונית, ב-`property_searches/{id}`. במחשב הסריקה רץ רכיב רקע:

- **כל 5 דקות** הוא שואל את הדסק (`op: poll`) אם לחצו "סרוק עכשיו", ומריץ רק את החיפושים שהתבקשו.
- **פעם ביום** הוא סורק את כל החיפושים הפעילים.
- לכל חיפוש הוא מדווח התחלה / תקלה (`op: report`) ושולח תוצאות עם `search_id`.
- בפעם הראשונה, כשאין חיפושים בדסק, החיפוש המקומי שלו מיובא אוטומטית (מסמך `local`).

`settings/nadlanScan.agentSeenAt` מתעדכן בכל שאילתה — מזה הדסק יודע אם המחשב מחובר.

## קבצים

| קובץ | תפקיד |
|---|---|
| `functions/nadlan.js` | הכתובת עצמה: בדיקת הקוד הסודי (`NADLAN_TOKEN`) |
| `functions/nadlan-core.js` | ניקוי הקלט, שמירה, היסטוריית מחיר, קליטת סימוני מעקב |
| `functions/test/nadlan-core.test.js` | בדיקות (`cd functions && npm test`) |
| `js/crm-properties.js` | הלשונית ב-Desk |
| `firestore.rules` → `properties` | בעלים קוראים; מעדכנים רק `status / notes / favorite` |

## מה הקוד הסודי מאפשר

להוסיף ולעדכן נכסים, לקרוא את הגדרות החיפושים, ולדווח על מצב סריקה. אי אפשר לקרוא דרכו לידים, תיקים, מסמכים או את המעקב על הנכסים, ואי אפשר לשנות דרכו את שדות המעקב אחרי שמישהו נגע בנכס ב-Desk.

## התקנה (פעם אחת)

1. יצירת קוד ושמירתו כסוד (הקוד נשמר גם בקובץ בשולחן העבודה, כדי להעביר אותו למחשב הסריקה):

   ```
   openssl rand -hex 24 | tee ~/Desktop/nadlan-desk/קוד-חיבור.txt | firebase functions:secrets:set NADLAN_TOKEN --data-file=- --project horizon-psagot-group-ccbe6
   ```

2. העלאת הפונקציה והחוקים:

   ```
   firebase deploy --only functions:nadlanIngest,firestore:rules --project horizon-psagot-group-ccbe6
   ```

3. במחשב הסריקה: להתקין את חבילת העדכון ולהריץ `הגדרת דסק.bat` עם הקוד.

## אחרי כל העלאה של הפונקציה

הארגון לא מרשה גישת `allUsers`, ולכן צריך לוודא שבדיקת הגישה של גוגל כבויה על השירות (האבטחה היא הקוד הסודי). בדיקה: `curl -X POST <הכתובת>` צריך להחזיר 401 ולא 403. אם 403 — ב-Cloud Shell:

```
gcloud run services update nadlaningest --region=europe-west1 --no-invoker-iam-check --project=horizon-psagot-group-ccbe6
```

## החלפת קוד

להריץ שוב את שלב 1 ואת ההעלאה של הפונקציה, ולהריץ שוב `הגדרת דסק.bat` במחשב הסריקה. הקוד הישן מפסיק לעבוד.

## מגבלות ידועות

- נכס שלא הופיע 3 ימים בסריקות של החיפושים שלו, או שכל החיפושים שלו נמחקו/הושהו, מוצג כ"ירד מהאתר".
- "סרוק עכשיו" עובד רק כשמחשב הסריקה דולק, ומוגבל לסריקה אחת לחיפוש ב-45 דקות.
- עיר חדשה בלי ייצוא מתוכנת מידע נדל"ן אצל הסורק תקבל הערכה חלשה (הדסק מתריע על זה בשורת החיפוש).
- ההערכה היא כלי לאיתור ולא שומה.
- נתוני העסקאות של מידע נדל"ן לא נשלחים ל-Desk, רק תוצאת ההערכה.
