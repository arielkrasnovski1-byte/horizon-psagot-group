Accessibility Statement

Horizon Psagot Group is committed to enabling equal access to the website for all users.

Our Accessibility Commitment

We work to make our website accessible in order to enable equal access and optimal use for people with disabilities, in accordance with the Equal Rights for People with Disabilities Law, 5758-1998, and the Equal Rights for People with Disabilities (Accessibility Adjustments for Service) Regulations, 5773-2013.

Accessibility Standards

The site complies with Israeli Standard 5568 at level AA, based on the WCAG 2.0 guidelines of the W3C organization at level AA.

Accessibility Widget

A floating accessibility button is available on every page of the site (person icon in a blue circle), located in the bottom-left corner. Clicking it opens a menu with the following options:

  • Three text-size levels (Large / X-Large / XX-Large)
  • High contrast and inverted contrast (for visual impairment)
  • Highlight links with a thick underline
  • Stop animations (for users sensitive to motion)
  • Readable font (clear Arial, increased spacing, friendly for dyslexia)
  • Large mouse cursor (for visual / motor needs)
  • Full reset of all settings

Your preferences are saved automatically in the browser, so on your next visit they will apply immediately.

Additional Accessibility Adjustments

  • Full Hebrew support with right-to-left (RTL) direction; English support with LTR
  • Semantic HTML structure with proper tagging of site areas (header, navigation, main content, footer)
  • Consistent heading hierarchy (H1-H6) enabling easy navigation for screen readers
  • Alternative text (alt) for images and visual elements
  • Standard color contrast between text and background
  • Full keyboard navigation capability (Tab, Enter, Escape)
  • Visible focus indication on all interactive elements
  • "Skip to main content" link at the start of every page
  • Respect for the user's reduce-motion preference (prefers-reduced-motion)
  • Compatibility with common assistive technologies (screen readers such as NVDA, JAWS, VoiceOver)
  • Accessible forms with proper field labeling and error messages
  • Responsive design enabling use on any screen size and device

Screen Readers

The site has been tested for compatibility with the following screen readers: NVDA (Windows), JAWS (Windows), VoiceOver (macOS / iOS), and TalkBack (Android).

Supported Browsers

The site has been tested and works on the latest versions of: Chrome, Firefox, Safari, Edge — on desktop and mobile devices.

Known Limitations & Exceptions

Specific accessibility difficulties may occasionally arise in certain parts of the site. We work on an ongoing basis to improve accessibility. If you encounter an access difficulty, please contact us and we will work to fix it as soon as possible.

Contacting the Accessibility Coordinator

If you have encountered an accessibility issue on the site, please contact us and we'll be glad to help:
